# Third-Party Licenses

Full license texts for every open-source component bundled with or used by Tabrok. Files are
organized by ecosystem (`npm/`, `python/`, `frameworks/`); each begins with the component name,
version, and license identifier, followed by the complete license text as shipped or published by
the project. Where an upstream wheel tarball bundles no license file, the standard license-family
text is reproduced and clearly marked.

These texts are redistributed with the application inside
`Tabrok.app/Contents/Resources/THIRD-PARTY-LICENSES/`. Note: the complete Chromium notices
(`LICENSES.chromium.html`, ~20 MB) ship inside every app bundle automatically and are referenced
in `frameworks/chromium-README.txt` rather than duplicated here.

These texts do not apply to Tabrok's own code, which is covered by the proprietary `LICENSE` in
the repository root.
