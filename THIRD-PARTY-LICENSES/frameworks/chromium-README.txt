Chromium — BSD-3-Clause and additional open-source licenses
========================================================================

The Chromium project and the ~1,500 third-party components it bundles are covered by the
Chromium license notices (BSD-3-Clause plus a large set of additional licenses).

The COMPLETE notices (~20 MB) are generated automatically by electron-builder into every
distributed application at:

    Tabrok.app/Contents/Resources/LICENSES.chromium.html

They are intentionally not duplicated in this repository to keep it small; the file inside
each shipped application bundle is authoritative.
